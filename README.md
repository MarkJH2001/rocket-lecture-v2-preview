site/ 保存当前阶段评审版的静态文件。媒体按完整文件保存，原始字节、像素、帧率与时长保持一致；媒体来源见课件对应图注。原成品的 SHA-256 清单随站点保留，媒体站另附简洁入口页。

This repository serves the current review edition of Rocket Lecture on GitHub Pages. Media files retain their original bytes and quality. Source credits accompany each slide.
